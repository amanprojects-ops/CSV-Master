# CSV Master

CSV Master is a sleek, client-side web application for importing, transforming, and exporting CSV data. It features a modern, premium UI and processes all data directly in the browser for maximum privacy and speed.

## Features

- **Drag & Drop Upload:** Easily upload your CSV files through an intuitive interface.
- **Column Mapping & Filtering:** Select exactly which columns you want to keep and rename them on the fly.
- **Data Chunking:** Split large CSV files into smaller parts (specify rows per file) and export them neatly as a ZIP archive.
- **Client-Side Processing:** All parsing and transforming is done in your browser. No data is sent to a server, ensuring your data remains private.
- **Modern UI:** Built with HTML, CSS (Glassmorphism design), and Vanilla JavaScript for a fast and beautiful experience.

## Getting Started

1. Clone the repository or download the source code.
2. Open `index.html` in your modern web browser.
3. Upload a CSV file and start transforming!

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [PapaParse](https://www.papaparse.com/) for fast CSV processing
- [JSZip](https://stuk.github.io/jszip/) for client-side ZIP generation
- [Phosphor Icons](https://phosphoricons.com/) for beautiful icons
